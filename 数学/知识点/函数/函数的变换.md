# 函数的变换

## 平移变换
>### - 沿y轴方向的平移
>- 对于$f(x)$，当它向上平移1单位后，即可视作对所有的$x$，其$f(x)$的结果都比原来大了1。即平移后的结果为$f(x)+1$
>- 因此可得。对任意的函数$f(x)$，要想改变它的高度/沿y轴方向平移，我们可以为它加上一个常数。该常数大于0即为上移，反之下移
>### - 沿x轴方向的平移
>- 我们可以将横向平移视作"函数值的错位读取"。例如对于函数$f(x)$，当函数向左平移1单位后，$f(0)$却错开了一位，读取到了$f(1)$的函数值；同理，$f(1)$也会错位读取到$f(2)的函数值，以此类推$
>- 因此，当函数向左平移n个单位后，平移后的函数g(x)就会读取到原来f(x+n)的函数值
>- 因此可得，对于任意的函数$f(x)$，要想让它横向平移，即可让它的自变量加上一个常数。即：$f(x)$向左平移n个单位可得$f(x+n)$。例:$f(x)=x^2$，其向左平移1单位的函数为$f(x+1)=(x+1)^2=x^2+2x+1$
