# mdpack — Markdown 文件夹 → 单个 HTML 打包器

把一个文件夹内的所有 Markdown（含图片等资源）打包成**一个完全离线、可双击打开的单 HTML 文件**。

## 特性

- **单文件输出**：所有页面、图片（base64 内嵌）、KaTeX 公式字体、代码高亮主题全部打进一个 HTML，无网络依赖。
- **导航条**：返回上一个页面、回到首页、字号 ±/重置（localStorage 记忆）、深色/浅色模式切换。
- **左侧目录**：整个文档的文件树（按文件夹折叠、当前页高亮自动展开）+ 当前页标题大纲两个标签页。
- **自适应**：宽屏（≥1100px）侧栏默认展开，窄屏自动收起为抽屉，按钮随时切换。
- **链接重写**：md 间相对链接自动变为页面路由（hash 路由，浏览器前进/后退可用）；`页面.md#标题` 的页内锚点跳转同样支持；指向图片/其它文件的链接转 base64 data URI；坏链置灰并提示。
- **语法覆盖**：GFM 表格/删除线/任务列表、代码块高亮（常见语言）、行内与块级公式（`$...$` / `$$...$$`，KaTeX）、脚注、`==高亮==`、`~~删除~~`、上下标、缩写、定义列表、`{.class}` 属性、内嵌 HTML。

## 使用

```bash
cd autopacker
npm install          # 首次
node mdpack.mjs <要打包的文件夹> [选项]
```

| 选项 | 说明 |
| --- | --- |
| `--entry <文件>` | 入口 md（文件夹一级下），默认 `README.md` |
| `-o, --output <路径>` | 输出 html 路径，默认 `<文件夹名>.html` |
| `--title <标题>` | 文档标题，默认取入口文件的一级标题 |
| `--exclude <名称>` | 额外排除的文件/文件夹名（可多次使用） |
| `--mermaid` | 支持 ` ```mermaid ` 图表（需先 `npm i mermaid`） |

默认排除 `.git`、`.idea`、`node_modules` 和输出文件本身。

示例（打包本项目）：

```bash
node mdpack.mjs .. --exclude autopacker -o "../知识总结.html"
```

## 限制

- Markdown 里以内嵌 HTML 标签形式写的本地链接/图片不会改写（仅标准 Markdown 语法会被处理）。
- KaTeX 对不合法 LaTeX 仅告警并尽力渲染；极少数 mhchem 等扩展需自行加插件。
